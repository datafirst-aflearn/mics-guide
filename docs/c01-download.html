1 Getting MICS6 data

This chapter shows how to put MICS6 microdata on disk, ready for the rest of the guide.

MICS6 is the UNICEF round that first fielded the Foundational Learning Skills (FLS) module. You can obtain the files in two ways:

  1. UNICEF MICS: the original country survey files.
  2. IPUMS MICS: a custom extract with variables already aligned across the surveys you select.

Use UNICEF when you need the FLS assessment, country-specific items, or a single country. Use IPUMS when you want a pooled file of demographic, household, and schooling variables and have Stata to build the extract. A single-country study gains little from IPUMS.

UNICEF MICS IPUMS MICS
What you receive Original country survey files A custom extract with harmonised variables across selected surveys
Best for Country-specific items; the FLS assessment; reproducing MICS indicators Multi-country work on demographic, household, and schooling variables
Preparation More: files must be unpacked and, for pooled work, harmonised Less: IPUMS supplies syntax that builds the extract
Software R or Stata: the .sav files open in either Stata to build the extract; then R or Stata for analysis
Single-country work Use this Adds little: IPUMS earns its keep across surveys

AFLEARN recommendation

If the analysis uses foundational reading, do not use the IPUMS reading variables for surveys that administered more than one passage. IPUMS keeps one passage and can drop a large share of children who completed the assessment. AFLEARN reconstructs reading outcomes from the complete UNICEF files; you can merge that file onto an IPUMS extract.

The two routes complement each other: IPUMS for comparable background variables, UNICEF for every reading passage.

  • To download the UNICEF country files and unpack them with AFLEARN’s scripts, go to Getting UNICEF MICS files.
  • To build an IPUMS extract, go to Getting IPUMS MICS files.

1.1 Getting UNICEF MICS files

UNICEF releases MICS microdata as SPSS (.sav) files. The files already carry variable and value labels, so you can open them in R or Stata without a separate codebook.

1.1.1 Download the country files

  1. Open https://mics.unicef.org/surveys.
  2. Log in if the site asks you to. Dataset downloads usually need an account.
  3. Filter to the surveys you want: round MICS6, then region or countries, data type MICS, and status Completed.
  4. Click Download MICS datasets. UNICEF packs every matching survey into one zip, usually named MICS_Datasets.zip.

Make a project folder, for example MICS project, and save MICS_Datasets.zip in it.

1.1.2 Unpack with AFLEARN’s scripts

The bulk zip nests each survey in further archives and wrapper folders. Unpacking many countries by hand wastes time and invites path errors.

MICS_Datasets.zip
└── survey folder
    └── another archive
        └── wrapper folder
            ├── fs.sav
            ├── hh.sav
            └── ...

Download Script.zip and unzip it into the same project folder, so Script/ sits beside MICS_Datasets.zip:

MICS project/
├── MICS_Datasets.zip
└── Script/

In R, set the project folder as the working directory and source run-it.R:

setwd("C:/path/to/MICS project")
source("Script/run-it.R")

The working directory must be the folder that holds Script/. If it is not, the script stops before creating anything.

That one run unpacks the surveys and writes the AFLEARN analysis file. Later chapters explain those files. You do not need to source the other scripts on the first run.

After a successful run:

MICS project/
├── MICS_Datasets.zip
├── Script/
└── Data/
    ├── UNICEF/
    │   ├── BEN_2021_MICS6_v01_M/
    │   │   ├── fs.sav
    │   │   ├── hh.sav
    │   │   ├── hl.sav
    │   │   └── ...
    │   └── ...
    └── AFLEARN Harmonised Data/
        ├── mics6-crosswalk.xlsx
        └── mics6-fs-harmonised-v2.0.dta

Each survey then has a predictable path such as Data/UNICEF/BEN_2021_MICS6_v01_M/fs.sav.

If the UNICEF zip is not in the project folder, pass its path:

source("Script/prepare-mics-fs.R")
prepare_mics_data(zip = "C:/path/to/MICS_Datasets.zip")

Then source Script/run-it.R as usual, or source the remaining scripts from Script/ yourself.

1.1.3 Check the result

dir.exists("Data/UNICEF")
list.files("Data/UNICEF")
file.exists("Data/UNICEF/BEN_2021_MICS6_v01_M/fs.sav")

Open one SPSS file:

library(haven)
fs <- read_sav("Data/UNICEF/BEN_2021_MICS6_v01_M/fs.sav")
dim(fs)

Keep the original download

Keep the original UNICEF zip. The clean folders are for analysis; the zip is the unchanged source.

1.2 Getting IPUMS MICS files

IPUMS MICS builds a custom extract. You choose a unit of analysis, surveys, and variables. IPUMS returns the UNICEF source data plus Stata syntax that harmonises them. Registration is free and uses the same UNICEF MICS login. See Getting Started with IPUMS MICS.

If you need foundational reading, read the passage warning before you add reading variables to the cart.

1.2.1 Build the extract

  1. Open GET DATA and choose a unit of analysis. For the FLS module, use children aged 5–17.
  2. Select the MICS6 samples you need. Record the IPUMS sample identifiers, not only country names.
  3. Add variables to the Data Cart. Before you add one, check that it exists in your samples, that the universe matches, and that the codes are comparable. Keep identifiers, sample, and weight variables for linking and survey design.
  4. Create the extract. The download is source data plus Stata .do files. Run the main .do file to build the pooled dataset. An R workflow needs Stata once for this step; then read the .dta in R. See Opening an Extract.

One extract has one unit of analysis

Some household or parent items are already attached to the child file; others need a link. See linking units of analysis.

IPUMS documents each variable’s universe, codes, and questionnaire text. Comparisons go wrong when universes differ across surveys. See the IPUMS MICS FAQ.

1.2.2 Multi-passage reading

Do not use the IPUMS reading variables for a MICS6 survey that administered more than one passage.

IPUMS keeps one passage. Children assessed on another passage look like item non-response. They are missing by language or passage, and reading estimates can be badly wrong.

Malawi MICS 2019–20 is the clear case. IPUMS records 1,720 children on FLWORDSATTEMPT (English). The UNICEF files show 3,970 who attempted Chichewa, of whom 130 also attempted English. Treating the IPUMS variable as the Malawi reading sample drops most of the children who completed the assessment.

This limit applies to the harmonised reading variables in multi-passage surveys, not to the rest of IPUMS. AFLEARN rebuilds reading from the UNICEF files, all passages kept, in mics6-fs-harmonised-v2.0.dta (see Getting UNICEF MICS files). Merge that file onto the IPUMS child extract as shown in Attaching the AFLEARN file to IPUMS.
